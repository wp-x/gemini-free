# Gemini Free 2.0.0

Gemini Free 从 Mac 菜单栏工具升级为 macOS 和 Windows 桌面客户端。本次用 Go + MyGo 重写，加入完整界面，保留后台服务和菜单栏／托盘操作。

## 这次更新

- 新增 Windows x64 客户端、安装程序和独立可执行文件；macOS 安装包同时支持 Apple Silicon 和 Intel。
- 首页集中显示服务状态、请求模式和 API 地址，支持启动、停止和复制地址。
- 新增问答测试、模型列表、登录会话管理、连接设置、访问密钥和日志页面。
- 提供匿名模式与登录会话模式；支持手动导入、更新 Cookie 和同步网页参数。
- macOS 菜单栏常驻，不占用 Dock 图标；Cmd+W 关闭窗口后服务继续运行。
- 默认仅本机访问，可在设置中启用局域网访问并配置密钥。
- 重写 README，加入新版真实界面截图、双端安装说明和 API 接入示例。

## 升级

先退出旧版，再安装新版。2.0 使用独立配置，不会覆盖 Swift 版配置；需要重新设置端口、代理等选项，登录会话可从旧版配置导入 Cookie。

新版不再自动续期 Cookie。会话失效时，在登录会话页面手动更新。高级模型返回的路由或档位与请求不符时，程序继续明确报错。

## 下载

- `Gemini.Free.2.0.0.dmg`：macOS 12+，Apple Silicon / Intel。
- `Gemini.Free.Setup.2.0.0.amd64.exe`：Windows x64 安装包。
- `Gemini.Free.exe`：Windows x64 独立可执行文件，需要系统 WebView2。
- `SHA256SUMS.txt`：下载文件的 SHA-256 校验值。

macOS 使用本地签名，尚未公证；Windows 未配置发行者签名。

## 已知限制

Argon 高档仍可能返回档位不匹配或超时，此版本不承诺修复上游高档稳定性。模型名称属于本地别名，不能单凭名称确认实际版本。

目前提供 OpenAI Chat Completions 与 Anthropic Messages 文本接口；不提供 Responses API、Gemini 原生 API、图片输入或绘图接口。Token 计数是本地估算。
